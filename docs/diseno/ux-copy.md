# Textos de la interfaz

## Tono
- Tuteo siempre, frases cortas, cercano sin ser infantil.
- Para empresas: mismo tuteo, sin emojis.
- Botones: verbo + objeto ("Crear cuenta", "Publicar oferta"). Nunca "Enviar" u "OK".
- Errores: qué pasó + cómo arreglarlo.
- Pantallas vacías: invitar a la acción, no disculparse.
